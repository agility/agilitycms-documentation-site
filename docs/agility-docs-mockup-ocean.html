What the MCP server is

The MCP server lets an AI client, such as Claude, call Agility operations as tools. It is secured with OAuth 2.0 and Dynamic Client Registration, uses Streamable HTTP transport, and is listed in the Claude directory. High-stakes operations use confirmation gates, so a human approves before anything goes live.

claude · agility-mcp 
# Ask the agent to draft a bilingual post
create_content_item(
  instance: "13f09fe2-u",   # Demo Site 2026
  model:    "BlogPost",
  locales:  ["en-ca", "fr-ca"],
  status:   "staging"   # human approves the publish
)
i
You stay in control. Agents operate inside your permissions, your workflows, and your approval steps. Confirmation gates exist so speed never costs you a bad publish.
